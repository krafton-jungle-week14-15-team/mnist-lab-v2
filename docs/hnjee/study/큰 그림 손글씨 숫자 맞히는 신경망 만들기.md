# 큰 그림: 손글씨 숫자 맞히는 신경망 만들기

Nov 27, 2026 · @현지

주제는 하나다: 손글씨 이미지를 넣으면 숫자를 맞히는 블랙박스(신경망)를 만들고, 그 안의 다이얼 약 10만 개를 기계가 스스로 맞추게 하는 것. 2\~6장은 이 한 가지를 만드는 과정이다.

## 한 장으로 보기

만들려면 질문이 두 개다. 상자 안은 어떻게 생겼나(윗줄), 그리고 다이얼을 어떻게 맞추나(아랫줄 고리).

&#91;embedded content: 블랙박스와 학습 고리 · 2\~6장의 위치\]

## 질문 A. 상자 안은 어떻게 생겼나 (2·3장)

2·3장은 블랙박스의 안쪽 구조를 만드는 단계다. 이 단계가 끝나도 다이얼은 아무렇게나 맞춰져 있어서 엉터리 답을 낸다.

| 장 | 하는 일 | 핵심 |
| --- | --- | --- |
| 2장 | 부품 하나 이해 | 퍼셉트론 = 다이얼(w, b) 몇 개 달린 작은 판단기.&#32; 하나로는 XOR을 못 해서 층을 쌓아야 한다 |
| 3장 | 부품을 연결해 상자 완성 | Affine(행렬 곱) → ReLU → Affine → softmax.&#32; 입력 784개가 확률 10개가 된다 |

- 다이얼 = 가중치·편향(파라미터). MNIST 신경망에는 101,770개.
- 3장에서 계단 함수를 ReLU로 바꾸는 것도 질문 B를 위한 준비다. 다이얼을 조금 돌렸을 때 결과도 조금 변해야 기계가 방향을 잡을 수 있다.

## 질문 B. 다이얼 10만 개를 어떻게 맞추나 (4\~6장)

사람이 10만 개를 직접 맞출 수 없으니, 기계가 아래 고리를 수천 번 반복하며 스스로 맞춘다. 이게 학습이다.

1. 채점 (4장, loss): 답이 정답과 얼마나 다른지 숫자 하나로 잰다
2. 방향 계산 (5장, 역전파): 다이얼 10만 개 각각을 어느 쪽으로 돌려야 덜 틀리는지 빠르게 계산한다
3. 돌리기 (6장, SGD): 그 방향으로 다이얼을 조금씩 돌린다

그리고 다시 1번으로. 반복할수록 다이얼이 맞춰지고 상자가 손글씨를 잘 맞힌다.

## 과제 가이드 그림과 매칭

가이드 그림은 큰 그림의 전문 용어 버전이다. 윗줄(→)은 답 내기와 채점, 아랫줄(←)은 끝에서부터 거꾸로 가는 방향 계산이다.

```text
입력 -> Affine -> ReLU -> Affine -> logits -> Softmax + Cross Entropy
     <-   dx   <-  dx  <-   dx   <- gradient

Forward -> Loss -> Backward -> Update
```

윗줄 (→): Forward + Loss

| 가이드 용어 | 큰 그림 단어 | 장 |
| --- | --- | --- |
| 입력 | 손글씨 이미지 (784개 숫자) |  |
| Affine → ReLU → Affine | 블랙박스 안쪽. Affine의 W, b가 다이얼 | 3장 |
| logits | 마지막 층 점수 10개 | 3장 |
| Softmax | 점수를 확률로 = 답 | 3장 |
| Cross Entropy | 채점 (loss) | 4장 |

Softmax와 Cross Entropy는 과제에서 `SoftmaxWithLoss` 한 함수로 묶여 있다.

아랫줄 (←): Backward = 다이얼별 방향 계산 (5장 역전파)

- gradient: 채점 결과(loss)에서 출발하는 "어느 쪽으로 바꾸면 덜 틀릴까" 정보
- dx: 각 층이 그 정보를 앞 층으로 넘겨주는 것. 도미노가 한 칸씩 거꾸로 넘어가는 것
- ReLU가 변화를 끊지 않는다 = dx가 ReLU 칸을 통과할 수 있다
- 정확한 뜻은 4\~5장에서 배운다

맨 아래 줄: 학습 고리

| 가이드 | 큰 그림 |
| --- | --- |
| Forward | 상자에 넣어서 답 내기 (= 추론) |
| Loss | 채점 |
| Backward | 다이얼별 방향 계산 |
| Update | 다이얼 조금 돌리기 (6장 SGD) |

이 네 개를 반복하는 게 학습이고, 추론은 그 첫 단계(Forward)만 하는 것이다.

과제 3일도 이 그림 순서 그대로다. 지금은 2·3장(질문 A)을 이해했고, 다음은 4장 채점(loss)이다.

| 날 | 그림에서 | 구현할 함수 | 책 |
